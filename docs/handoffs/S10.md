Nastavljamo open-ledger (`/Users/ms/git/minka/open-ledger`, javni `pinkainc/open-ledger`, MIT, radi se izravno na `main`): open-source ledger kompatibilan s Minkom, kao što su MinIO i R2 kompatibilni sa S3. Minka je crna kutija, a njezin klijentski API (`@minka/ledger-sdk` i `minka` CLI) je ugovor. Sve je u TypeScriptu. `../docs.minka.io` je read-only SSOT (docs, `_raw/openapi.yaml`, CLI referenca). Memory je u ovom projektu, pročitaj ga.

Ovo je sesija **S10** iz lanca. **Prvo pročitaj:** `docs/handoffs/README.md` (lanac i zajednička pravila, obavezno), `docs/2026-10-10-plan-do-paritete.md`, `TODO.md`, vrh `FINDINGS.md` i `conformance/divergences.json`.

Ako se ponovi, u `run.sh` dodaj čekanje dok se ime tunela ne razrješava i javno (npr. `dig @1.1.1.1`).

- Benchmark (`scripts/bench.ts`) daje temelj za točku 5 (agregati dnevnih limita): izmjeri prije i poslije s limitima uključenima.

**Zadatak S10: DTC, labels i ostatak backloga.** Raspodjela je iz pregleda TODO-a 2026-10-11, stavke su u `TODO.md` označene s „S10”. Ovo nije rezerva, ovaj posao postoji.
1. **DTC policy** (`schema: dtc`; u specu od 2.46, docs nemaju prozu, SDK 2.47 ima tipove): konfigurabilni 2PC koraci `dtc.prepare/commit/notify/setStatus` i `core.commit`, prioritet, filter po koraku, `suspendTimeoutMs`. Plan je u `docs/2026-10-10-plan-do-paritete.md` (red S10–S11). Prvo snimi ponašanje na sandboxu, s ograničenim scenarijem i bez petlji. Ovo je najveći komad.
2. **Labels:** `meta.labels` koje postavlja proof (`structuring-data/labels.md`). Danas svaka promjena nosi `labels: null`. Zatim **labels policies** (`labels-policies.md`): `record` i `filter` biraju zapise, `values[].labels` je whitelist, a bez policyja koji se podudara dopušteno je sve. Prvo snimka.
3. `filter` na processing policyjima (spec `policy-filter`; status policyji ga već primjenjuju u `status.ts`). Snimi i primijeni u `forwarding.ts`.
4. Snimi `signer.factor.oauth.allowClientCredentials`. Implementirano je, nije snimljeno.
5. Dnevni limiti trebaju agregate umjesto čitanja svih intenta. Benchmark iz S9 pokazuje prije i poslije, a `daywindow` i `limits2`–`limits5` su regresija.
6. Na kraju provjeri ima li docs mirror (`../docs.minka.io`, datum je u memory `minka-docs-ssot-repo`) ili sandbox noviju verziju od zadnje snimke. Ako ima, ponovno snimi pogođene razine.
