## Zadatak W2 (iz plana, dopunjen) · Opus 5.5, effort medium

`scripts/site-facts.ts`: iz `COVERAGE.md` (ili `conformance/coverage.ts`), fixtures
(`conformance/fixtures/*.jsonl`), broja testova, verzije iz servera i rezultata razina
upiše `site/src/data/facts.json`. Način `--check` pada ako je JSON zastario; dodaj ga u
`scripts/check.sh`. Unit test za parsere (`server/test/` ili uz skriptu, kako repo već radi;
`npm test` ga mora pokupiti).

Polja (puna tablica s izvorima i trenutnim vrijednostima: `site/CONTENT.md`, „Popis brojki
za W2”): `operations.{total,implemented,confirmed,spec}`, `resources[]` (16 redaka, zbroj
146), `version.{server,sandbox}`, `fixtures.{reference,bridge}`,
`exchanges.{client,bridge,total}`, `scenarios.count`, `tests.{postgres,memory,files}`,
`server.sourceFiles`, `divergences.{count,fixtures}`, `findings.{sections,firstDate,lastDate}`,
`levels[]` (id, scope, clientMatched/Total, bridgeMatched/Total, differ), `interop.*`
(325, 31, 78), `lineCoverage` (s datumom i commitom), `footprint.ledgers`, `ports`,
`node.engine`, `license`, `bench` (datirana konstanta, izvan `--check`).

Pravila koja je W1 naučio:

- **`--check` mora biti deterministična.** Bez vremenske oznake u `facts.json`. Commit u
  datoteku samo ako je to commit zadnje promjene ulaza, inače pada nakon svakog commita.
- **Broj testova:** čitaj `ℹ tests N` iz `.rec/test.log` koji piše `scripts/check.sh`
  (ne pokreći suite dvaput); ako loga nema, jasna poruka, ne tiha nula. Napomena: u
  `check.sh` je `DATABASE_URL` postavljen pa je to broj s Postgresom (446).
- **Razine iz fixtura, ne iz README teksta.** Broji retke fixtura; `differ` iz
  `divergences.json`. Zatim provjeri da README tablica (`README.md:50-62`) daje iste
  brojke; ako ne, README je kriv i zapiši to.
- `COVERAGE.md` operacije imaju backslashe (`access/\!check`); ako ih W6 čita, razescapiraj.
- `scripts/check.sh` već ima korak `coverage`; stavi `--check` uz njega, prije `footprint`.
- Ne snimaj protiv sandboxa. Ne dodaji ovisnosti u root `package.json`.

**Gotovo kad:** `npm run check` zelen, `site/src/data/facts.json` postoji i
poklapa se s README tablicom (ili je README ispravljen i to zapisano), unit test za
parsere prolazi.
