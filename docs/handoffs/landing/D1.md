- README repoa ima redak „Website: open-ledger.mpt.hr — **not live yet**”.

## Postupak (korisnik pokreće ili odobrava svaki korak)

1. Provjera prije: `npm run check` (korijen) i `npm --prefix site run deploy:dry-run` zeleni;
   radno stablo čisto, `main` pushan.
2. Prijava, **korisnik sam** u Claude Code promptu: `! cd site && npx wrangler login`
   (pinani wrangler iz `site/node_modules`), račun koji drži zonu `mpt.hr`. Zatim
   `cd site && npx wrangler whoami` pokaže račun.
3. Provjera DNS-a: u zoni `mpt.hr` ne smije postojati zapis `open-ledger` (custom domain ga
   stvara sam; postojeći CNAME/A treba prvo maknuti, to odlučuje korisnik).
4. Deploy (u `site/`): `npm run build && npx wrangler deploy`. Očekivano: Worker
   `open-ledger-site`, custom domain `open-ledger.mpt.hr`, bez `*.workers.dev`.
5. Provjera živo (Brave `ms@ff.hr`, claude-in-chrome, `navigate` u kontroliranom tabu, ne `open`):
   `curl -sI https://open-ledger.mpt.hr/en/` 200; `/en` → `/en/`; `/nope/` 404 s dvojezičnom
   stranicom; `/og-en.png`, `/llms.txt`, `/sitemap-index.xml`, `/robots.txt` 200; certifikat
   valjan (prvi put može trebati par minuta). U Braveu: `/`, `/en/`, `/hr/`, coverage, findings
   na 360 i 1280 px; po želji Lighthouse protiv živog URL-a.
6. Nakon uspjeha: u README repoa makni „not live yet”, u `site/PLACEHOLDERS.md` izbriši redak
   „Prvi deploy” i „Oznaka not live yet”, označi D1 u `TODO.md` i u tablici
   `docs/handoffs/landing/README.md`, ažuriraj „Stanje” u planu. Commit, push.
7. Opcionalno, samo ako korisnik želi: GitHub Action `.github/workflows/site.yml` na push u
   `site/**` (i `COVERAGE.md`, `FINDINGS.md`, `conformance/divergences.json`, jer se stranica
   gradi iz njih): `actions/checkout`, `actions/setup-node`, `npm ci` u `site/`,
   `npm run build`, `cloudflare/wrangler-action` s `workingDirectory: site`. Secret
   `CLOUDFLARE_API_TOKEN` (predložak „Edit Cloudflare Workers”, ograničen na zonu `mpt.hr`) i
   `CLOUDFLARE_ACCOUNT_ID` postavlja korisnik u GitHub postavkama repoa. Napomena: build u CI-ju
   ne treba Postgres ni `rsvg-convert` (`facts.json` i OG PNG-ovi su commitani i provjereni
   lokalnim `npm run check`).

Povratak (ako nešto ne valja): `npx wrangler rollback` ili u dashboardu makni custom domain;
brisanje Workera (`wrangler delete`) samo na korisnikov zahtjev.
