## Što je W2 napravio

- `scripts/site-facts.ts` piše `site/src/data/facts.json`; `--check` pada ako JSON nije
  ono što repo kaže **ili** ako README proza (`N with Postgres`, `So far: N cases in M
  fixtures`) ne odgovara. Korak `site facts` je u `scripts/check.sh` odmah iza `coverage`.
- Parseri su izvezeni i testirani u `server/test/site-facts.test.ts` (5 testova, `npm test`
  ih kupi). Ukupno sada **451** unit test s Postgresom.
- README ispravljen: 217 → 451 testova, „one” → „21 cases in 14 fixtures”, bench
  16 ledgera 450–530/s → ~400–450/s (450–530 je bilo krivo pročitano vrijeme prihvata
  0,45–0,53 s iz BENCH dokumenta), redak L7 sad navodi fixture `l7` (threadovi):
  33/36 klijentskih, 9/12 bridge, 3 + 3 namjerno drukčije. Ostale README brojke razina
  poklapaju se s `facts.json` (provjereno brojanjem).

## Odluke W2 (mijenjaju sljedeće korake)

- **Bez `generated.commit`/`date`** u JSON-u: izlaz je determinističan, `--check` pada
  samo kad se ulaz promijeni. Stranica ne smije prikazivati „generirano dana”.
- **`tests.memory` izbačen**: zahtijevao bi drugo pokretanje suitea bez Postgresa.
  Stranica prikazuje samo `tests.postgres`.
- `footprint.ledgers` broji različite ledgere (152), ne retke (271 događaj, `footprint.events`). `tests.files` broji `*.test.ts` (32, s novim testom), `scenarios.count` ne broji
  `common.ts` (64, jednako broju reference fixtura).
- `bench` je konstanta u skripti (`BENCH`, izvor `docs/2026-10-19-nastanak-benchmark.md`,
  izmjereno 2026-10-19), u JSON-u s datumom. `lineCoverage` se kopira iz
  `conformance/line-coverage.json` s `measured` i `commit` (2026-10-17, `3054926`):
  prikazuj samo s datumom.
- `levels[]` je u README redoslijedu: `{ id, scope, fixtures: [{ name, clientTotal,
  clientMatched, bridgeTotal, bridgeMatched, differ }] }`. `matched = total − listed
  divergences`; vrijedi jer `npm run check` replaya svaki fixture i pada na svakom
  drugom odstupanju.
- **Radni tok kad se doda test ili fixture:** `npm run check` padne na `site facts`;
  `npx tsx scripts/site-facts.ts` (čita `.rec/test.log` iz te provjere), ispravi README
  brojku ako je javljena, ponovno check.

## Zadatak W3 (iz plana, dopunjen) · Opus 5.5, effort medium

`site/` s Astrom (zadnja stabilna verzija, **točno pinana**: `npm view astro version`,
bez `^`), `@astrojs/sitemap`, i18n routing `hr` i `en` (`/hr/…`, `/en/…`; `/` šalje
na jezik preglednika, s `hreflang` alternativama), layout s headerom (logo-tekst,
navigacija, prekidač jezika i teme), podnožje (disclaimer o Minki kao u README odjeljku
License, MIT, link na `github.com/pinkainc/open-ledger`), tokeni boja na `:root` za
svijetlu i tamnu temu, lokalni font stack. Prazne sekcije s naslovima (12 odjeljaka iz
`site/CONTENT.md`). `npm --prefix site run build` daje `site/dist/`.

Dopune iz W2:

- `site/` ima vlastiti `package.json` i `package-lock.json`; ništa ne dodaj u root
  `package.json`. `npm run check` ne gradi stranicu (to radi orkestrator).
- Brojke uvezi iz `site/src/data/facts.json` (`import facts from '../data/facts.json'`),
  nijednu ne piši ručno. U W3 je dovoljno da jedan placeholder (npr. hero
  „146/146 operations”) dokaže da uvoz radi.
- Bez JS-a na klijentu osim prekidača teme i jezika; tema bez bljeska (inline skripta u
  `<head>`), poštuje `prefers-color-scheme`.
- Provjera u browseru prema README pravilima (Brave `ms@ff.hr`), dev server s
  `run_in_background`, ugasi ga na kraju.

**Orkestrator provjerava:** `/hr/` i `/en/` se otvaraju, prekidači rade, nema
horizontalnog scrolla na 360 px.
